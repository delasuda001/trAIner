
# Plan de développement

## Phase 1 : Initialisation

- Créer le projet Next.js TypeScript.
- Ajouter Tailwind.
- Configurer ESLint et Prettier.
- Ajouter Vitest.
- Ajouter Drizzle et SQLite.
- Créer .env.example.
- Mettre en place une page d'accueil.
- Vérifier que lint, typecheck et tests passent.

## Phase 2 : Client Intervals.icu

- Créer le client serveur.
- Définir les schémas Zod.
- Ajouter une route pour les activités récentes.
- Créer une page de liste.
- Ajouter une gestion d'erreur et d'état de chargement.

## Phase 3 : Détail d'activité

- Charger le détail d'activité.
- Charger les laps et streams.
- Afficher les statistiques.
- Créer les graphiques.
- Ajouter des fixtures de tests.

## Phase 4 : Moteur de métriques

- Créer des fonctions pures.
- Calculer les métriques par intervalle.
- Calculer régularité et évolution intra-séance.
- Ajouter les tests unitaires.
- Afficher les résultats sur la page activité.

## Phase 5 : Contexte et stockage local

- Créer les tables SQLite.
- Ajouter le formulaire de ressenti.
- Sauvegarder notes et contexte.
- Ajouter les analyses et actions.

## Phase 6 : Analyse IA

- Construire le résumé anonymisé.
- Définir le schéma de réponse Gemini.
- Générer un débrief à la demande.
- Valider la réponse.
- Stocker et afficher le débrief.

## Phase 7 : Comparaison historique

- Définir les règles de similarité.
- Charger les activités comparables.
- Ajouter une baseline.
- Enrichir le débrief IA.
